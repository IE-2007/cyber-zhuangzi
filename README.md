# 赛博庄子

> 以庄入言，以典化意

赛博庄子是一个将现代白话改写为庄子哲学气质表达的工具。内置 208 条《庄子》典故数据，通过 RAG 混合检索与大语言模型生成，将日常之言化作庄周之语。

**核心理念：** 不是简单的文言文翻译，而是用庄子的思维方式重新表达现代生活。

---

本项目灵感来源于 [**合乎庄子 (hehuzhouli.com)**](https://hehuzhouli.com/)，感谢原作者的创意与启发。赛博庄子在此基础上进行了功能拓展与技术实现，新增了典故问答、Coze Skill 集成、本地文件版等形态，让更多人能够体验庄子风格的文本转化。

---

## 功能模式

| 模式 | 说明 |
|------|------|
| **典故问答** | 查询《庄子》典故的含义与出处 |
| **入道** | 将现代白话改写为《庄子》古文翻译风格 |
| **出寓言** | 将《庄子》原文或《庄子》风格文本翻译回现代白话 |

## 使用方式

### 1. 在线演示

直接在 [Demo 页面](https://ie-2007.github.io/cyber-zhuangzi/) 体验典故问答、入道、出寓言功能。

### 2. Coze Skill 版本

在扣子平台 (coze.cn) 安装"赛博庄子"技能后，在任意对话中直接使用。技能会自动识别你的意图（入道/出寓言），无需调用外部 API。

- **安装方式：** 扣子平台 → 技能商店 → 搜索"赛博庄子"
- **使用方法：** 对话中说"帮我翻译成庄子风格"或"入道"等触发词

### 3. 本地文件版本

下载 `赛博庄子-v1.0-standalone.md` 文件，将完整内容复制到任意 AI 对话框（ChatGPT、Claude、Gemini 等）即可使用。无需注册扣子账号，不依赖任何平台。

- 包含完整的 prompt 指令和 208 条典故数据
- 即开即用，适合离线场景或无 coze 账号的用户

## 技术栈

- **后端：** Python FastAPI
- **前端：** 原生 HTML/CSS/JS
- **数据：** 208 条庄子典故数据（JSON）
- **生成：** LLM 大语言模型

---

## 设计原则

- **古文翻译腔：** 像中学课本《庄子》选篇的白话译文，一本正经但通俗易懂
- **典故节制：** 短篇 1 个、中篇 1-2 个、长篇 2-3 个，典故占比不超 30%
- **语言纯净：** 禁止白话口语词、现代化句式，保持古典气质
- **自然嵌入：** 典故不铺垫、不标注出处，像预设读者有知识储备
